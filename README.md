# 🧪 development-environment

Ambiente de Desenvolvimento - Desafio Prático Iniciante

Este projeto foi desenvolvido como parte das atividades do curso de Sistemas para Internet. O objetivo principal era compreender a estrutura básica de uma API utilizando Java com Spring Boot, aplicando boas práticas de organização de código e endpoints RESTful.


## 🧠 Descrição

### Aula 1: Endpoint que Exibe seu Nome

Foi criado um endpoint simples utilizando o padrão de projeto Controller para exibir uma mensagem com o nome do aluno. Utilizamos o Insomnia para testar e visualizar a resposta da requisição GET.

## 📌 Considerações Finais

Este projeto representa os primeiros passos com desenvolvimento de APIs RESTful em Java, focando no entendimento de estrutura de diretórios, configuração básica do Spring Boot e testes de rotas com ferramentas como Insomnia. É o início de um processo contínuo de aprendizado que será ampliado com novas funcionalidades e camadas nas próximas aulas.
